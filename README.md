# ANN Binary Classification Using the `make_moons` Dataset

## Project Overview
This project demonstrates Artificial Neural Network (ANN) binary classification using the `make_moons` dataset from Scikit-learn. The program trains a neural network to classify data points into two classes, evaluates its performance, prints sample predictions, and visualizes the results with graphs.

## Objectives
- Generate a two-class dataset using `make_moons`.
- Split the data into training and testing sets.
- Standardize the input features.
- Build and train an ANN using PyTorch.
- Evaluate the model using test accuracy and training loss.
- Display sample actual and predicted classes.
- Plot the ANN decision boundary and compare actual classes with predicted classes.

## Technologies Used
- Python
- Scikit-learn
- PyTorch
- NumPy
- Matplotlib

## Dataset
The program creates 1,000 samples with two input features and two output classes using:

```python
make_moons(n_samples=1000, noise=0.2, random_state=42)
```

The dataset is split into:
- 80% training data
- 20% testing data

`StandardScaler` is used to standardize the input features.

## ANN Architecture

| Layer | Description |
|---|---|
| Input layer | 2 input features |
| Hidden layer 1 | 16 neurons with ReLU activation |
| Hidden layer 2 | 8 neurons with ReLU activation |
| Output layer | 1 neuron with Sigmoid activation |

### Training Parameters
- Loss function: Binary Cross-Entropy (`BCELoss`)
- Optimizer: Adam
- Learning rate: 0.01
- Training epochs: 200
- Classification threshold: 0.5

## How the Program Works
1. Imports the required Python libraries.
2. Generates the `make_moons` dataset.
3. Splits the data into training and testing sets.
4. Standardizes the input features.
5. Converts the data into PyTorch tensors.
6. Builds the ANN model.
7. Trains the model for 200 epochs.
8. Calculates test accuracy and training loss.
9. Prints ten sample actual and predicted labels.
10. Plots the ANN decision boundary.
11. Displays graphs comparing actual classes and predicted classes.

## How to Run in Google Colab

## Expected Output
The program displays:
- Final training loss
- Test accuracy percentage
- Ten sample actual-versus-predicted class labels
- ANN prediction and decision-boundary graph
- Actual classes graph
- ANN predicted classes graph

The exact accuracy and loss values are calculated when the program runs.

## Graph Descriptions
- **Decision Boundary:** Shows the regions assigned to each class by the ANN. The black line represents the 0.5 probability boundary.
- **Actual Classes:** Shows the original labels generated by `make_moons`.
- **ANN Predicted Classes:** Shows the labels predicted by the trained neural network.

## Conclusion
This project demonstrates how an Artificial Neural Network can learn a nonlinear decision boundary and classify data into two classes. The graphs help compare the original labels with the model's predictions.
